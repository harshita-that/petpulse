# PetPulse 🐾

Catch health changes before they become emergencies.

## What it is

Pet owners have no visibility into their pet's health between vet visits.
By the time something's obvious, it's already expensive.

PetPulse lets you photograph your pet's teeth, eyes, skin, or gait and get
instant AI health insights — catching the subtle signs you'd normally miss.

Currently: landing page live, core app in active development.

## Stack

Next.js 15 · TypeScript · Tailwind CSS · Framer Motion · React Three Fiber · Lenis · shadcn/ui

## Running locally

```bash
git clone https://github.com/your-username/petpulse
cd petpulse/frontend
npm install
npm run dev
```
